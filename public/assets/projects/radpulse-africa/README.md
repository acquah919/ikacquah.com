# RadPulse Africa assets

These are optimized WebP copies of the light and dark development screenshots supplied by the project owner. They retain the original screen contents and proportions. Source files were 1080 pixels wide; web copies are 900 pixels wide.

The portfolio content is maintained in `data/projects.ts`. Update the screenshot paths there when a new build changes a screen. The walkthrough uses Home, Equipment, Tasks, Records, More, and About. The creator screen accompanies the developer biography. Additional supplied screenshots are retained with the same naming convention.

Project facts come from the supplied `radpulse.docx`: Android, version 1.0.0, and ongoing development. The Expo link leads to the development project page.
